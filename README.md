# Marketing Measurement System (End-to-End)

## Overview

This project builds a unified marketing measurement system covering:

* Incrementality testing (Geo Lift, A/B)
* Marketing Mix Modeling (MMM)
* Attribution analysis
* Lead quality and LTV prediction
* Marketing data architecture (SQL + dbt)

---

## Objective

To move from **correlation-based attribution** to **causal, decision-ready measurement**.

---

## Project Structure

* `/docs` → business context, causal reasoning, playbooks
* `/notebooks` → analysis (geo lift, MMM, LTV)
* `/sql` → data modeling logic
* `/dbt` → production-grade transformation models
* `/data` → synthetic datasets
* `/dashboards` → reporting layer

---

## Key Questions Answered

* Which channels drive incremental revenue?
* How should marketing budget be allocated?
* Which leads are high-value vs low-value?
* How does attribution differ from causal impact?
